# Intelligent Student Assistant

## Project Overview
The Intelligent Student Assistant is a Python-based project designed to help students calculate their marks, check attendance, and get simple study suggestions.

## Features
1. Marks Calculator – calculates total marks and percentage.
2. Attendance Calculator – calculates attendance percentage and checks the 75% threshold.
3. Study Planner – provides study suggestions based on daily study hours.

## Technology Used
- Python 3
- Visual Studio Code

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

   python main.py

## Project Structure
- main.py – contains the program and its features.

## Limitations
The current version uses simple rule-based suggestions. It does not train a machine learning model or save student data permanently.
