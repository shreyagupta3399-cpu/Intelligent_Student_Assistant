# Project Statement

## Project Title
Intelligent Student Assistant

## Problem Statement
Students may need a simple tool to calculate their marks, check attendance, and organize their study time. Performing these calculations manually can take extra time.

## Objectives
- Calculate total marks and percentage.
- Calculate attendance percentage.
- Check whether attendance is at least 75%.
- Provide simple study suggestions based on available daily study hours.

## Target Users
School and college students.

## Scope
This project is a beginner-friendly Python application. It provides basic calculations and rule-based study suggestions.

## Main Modules
1. Marks Calculator
2. Attendance Calculator
3. Study Planner

## Technology
Python 3
